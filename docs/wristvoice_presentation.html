The goal & the constraints

Two tiny speech models on a watch — and why it's hard

What we want
  • Model 1 — general recognition, dictation & free speech, ≤ 10 MB
  • Model 2 — commands + intent/slot, always-on, ≤ 5 MB
  • Fully on-device, streaming, runs on the NPU
Why it's hard
  • Memory — 10+5 MB resident (RAM/OTA), not a compute limit
  • Power — commands must run 24/7 at eNPU milliwatts
  • Deployment — int4 on QNN/HTP, standard ops only

Reference point: the smallest compressed edge ASR in the 2026 literature is still ~670 MB. 10 MB is only reachable by designing small + distilling + int4.

05

The two models

Right head for each job

Model 1 · general · ≤ 10 MB

Streaming transducer (RNN-T) + aux CTC

  • Cache-aware chunked encoder (every frame encoded once)
  • Encoder = 85% of budget; Conformer-lite or Mamba/SSM
  • Mamba int4: 5.17 MB · Conformer int4: 6.51 MB
  • Transducer models word context — best for free dictation
Model 2 · commands · ≤ 5 MB

Conformer-CTC + FST + intent/slot

  • Open-vocab keywords (add a command by typing text)
  • On-device SLU: "timer for 5 min" → {intent:timer, num:5}
  • CTC streams trivially, cheap, always-on friendly
  • Built at 2.55 MB int8 (1.35 MB int4 target)

CTC for commands, transducer for dictation — the principled version of "Conformer without the decoder."

12

Engineering rigor

Real bugs, found and fixed — not a slideware demo

✓Tokenizer/label mismatch — Whisper's punctuation became "unknown" tokens; targets were unlearnable. Fixed with text normalization + matched tokenizer.
✓Missing LR warmup — the transducer loss oscillated on long utterances. Added warmup + cosine decay.
✓GPU RNN-T length mismatch — the CUDA kernel rejected approximate encoder lengths. Computed the exact subsampled length.
✓FLAC loading + --init fine-tuning — real-audio loaders and warm-start for on-device personalization.

How we get to the 10 MB general model

From proven pipeline to shipped product

01Data — commercial: Loquacious (25k h) + wrist recordings; research: SLURP / Speech Commands for real command voices.
02Label + distil — Whisper/Parakeet pseudo-labels → train the Zipformer transducer student (the pipeline already runs).
03Compress — int4 QAT + structured pruning → ≤ 10 MB, deployable ops.
04Personalize + deploy — on-device fine-tune (prototyped) → 3-graph ONNX → QNN context binary for the Hexagon.
